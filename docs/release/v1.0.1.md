# iqdb-flat v1.0.1

A fix release. No API changes.

## Fixed

- **NaN distances rank last.** Top-`k` selection ordered distances with
  `f32::total_cmp`, which puts a NaN with its sign bit set (the default NaN
  x86 arithmetic produces) below every number. A vector whose distance
  overflowed to that NaN came back as the best match, ahead of an exact one.
  Every NaN now ranks after every number, whatever its sign bit. Paired with
  `iqdb-distance` 1.0.1, finite vectors no longer produce NaN at all.

## Upgrading

Change the version to `1.0.1`. Nothing else is needed.
